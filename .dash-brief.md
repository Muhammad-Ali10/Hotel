# Stayora dashboard page — Figma-fidelity rewrite brief

You are rewriting ONE customer-dashboard page in an existing Next.js app to match
its Figma design exactly. The dashboard layout (header + left sidebar + footer)
already exists via `src/app/dashboard/layout.tsx` — build ONLY the MAIN content.

## Stack & conventions (match the existing code)
- Next.js 16 App Router, React 19, TS, Tailwind v4, shadcn/ui on **Base UI** (NOT Radix).
- Composition uses the **`render` prop**, never `asChild`: `<Button render={<Link href="/x">Go</Link>} />`.
- `lucide-react` v1.x — NO brand icons (Facebook/Twitter/etc don't exist). Generic icons only.
- Colors: **off-white + black** theme TOKENS only (`bg-card`, `bg-muted`, `text-muted-foreground`,
  `bg-primary`, `text-primary-foreground`, `border`, `ring`). No hardcoded hex except amber-400 for stars.
- Headings use `font-heading` (Inter). Body is Poppins (global). Match the existing dashboard
  home style (it was just rebuilt): page content is a `<div className="space-y-8">`, the page H1
  is `font-heading text-2xl font-semibold tracking-tight sm:text-3xl`.
- Images: `placeholderImage(seed,w,h)` (hotels) and `avatarImage(seed)` (faces) from `@/lib/images`,
  rendered with `next/image`. Formatters: `formatCurrency`, `formatDate` from `@/lib/format`.
- Status badges: reuse `import { StatusBadge } from "../_components/status-badge"` style — there is a
  shared one at `src/app/dashboard/_components/status-badge.tsx` (confirmed/completed/pending/cancelled).
  If your page isn't under that folder, you can import it via a relative path or replicate its mapping.
- shadcn components from `@/components/ui/*` (Card, Button, Badge, Input, Label, Switch, Select, Separator…).
- FULLY RESPONSIVE: full-width rows stack on mobile; multi-column grids collapse to 1 column.

## Hard rules
- Build ONLY your page's MAIN content (no header/sidebar/footer — the layout provides them).
- Match the Figma structure I give you EXACTLY: same sections, same controls, same card anatomy,
  no extra tabs/buttons/subtitles that the Figma doesn't show, and don't omit ones it does show.
- Put screen-local components in your route's `_components/` folder. Do NOT edit shared files
  (layout, config, lib, ui, the shared data modules) — import from them.
- Double quotes, no semicolons, `cn()` from `@/lib/utils` for conditional classes.
- Do NOT run a build or dev server. Return the list of files you created/changed.
